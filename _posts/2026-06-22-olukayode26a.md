title: Machine Learning Prediction of Groundwater Contamination Vulnerability Using
  Hydrogeophysical Indicators in Ibadan
abstract: This study employs machine learning to estimate groundwater contamination
  vulnerability in Ibadan, southwestern Nigeria, using hydrogeophysical indicators
  from 353 Vertical Electrical Sounding (VES) surveys. A Random Forest classifier
  trained on GOD/GODT vulnerability labels achieved accuracy = 0.94, precision = 0.94,
  recall = 0.93, F1-score = 0.93, and AUC = 0.95. Overburden thickness and longitudinal
  conductance were the most significant predictors. The model identified fifteen high-vulnerability
  zones versus nine from conventional GODT, demonstrating its ability to capture nonlinear
  interactions that conventional methods miss.
